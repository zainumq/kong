Demo ini memakai kontrak marketplace $KONG yang sama persis dengan versi mainnet — hanya saja berjalan di BSC Testnet dengan token test. Ambil tBNB dari faucet, mint test USDT, klaim satu test pass gratis, lalu coba jual beli seperti di mainnet nanti.

Non-custodial: pass tetap di wallet penjual selama ter-listing. Dana terbagi otomatis — penjual 94%, royalti 5% ke treasury, fee marketplace 1%.

Harga listing tidak boleh di bawah floor tier-nya (sama dengan harga mint): 1 / 1,5 / 2 test USDT.

Cara kerja

  1. List — approve kontrak market atas pass Anda, lalu tentukan harga (test USDT atau tBNB). Harga tidak boleh di bawah floor tier-nya. Pass tetap di wallet Anda.
  2. Beli — untuk listing test USDT, approve test USDT sebesar harga dulu; untuk listing tBNB, tBNB dikirim bersama transaksi beli. Dana terbagi otomatis dalam satu transaksi: penjual 94%, royalti 5% ke treasury, fee 1% ditampung di kontrak market. Pembelian dilindungi batas harga maksimum: bila harga listing naik di atas harga yang ditampilkan sebelum transaksi diproses, transaksi dibatalkan otomatis.
  3. Ubah / batal — penjual bisa mengubah harga atau membatalkan listing kapan saja (biaya gas tBNB saja).
  4. Tidak ada klaim / refund di testnet — test pass tidak bisa diklaim menjadi $KONG dan tidak ada refund. Di mainnet nanti, pemilik bisa klaim (setelah graduation) atau refund (bila sale gagal) kapan saja, bahkan saat pass ter-listing.
